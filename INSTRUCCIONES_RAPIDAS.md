# 🚀 Cómo correr el proyecto Vision Tracking

Sigue estos 3 pasos sencillos para ejecutar la aplicación tú misma:

## 1. Abre la Terminal
Busca "Terminal" en tus aplicaciones o Spotlight (Cmd + Espacio) y ábrela.

## 2. Ve a la carpeta del proyecto
Copia y pega el siguiente comando en la terminal y presiona **Enter**:

```bash
cd /Users/gregis/Documents/vision-tracking-project
```

## 3. Ejecuta la aplicación
Copia y pega este comando y presiona **Enter**:

```bash
uv run streamlit run src/app.py
```

---

### ¿Qué sucederá?
- Verás algunos mensajes en la terminal.
- Se abrirá automáticamente una pestaña en tu navegador (o puedes ir a `http://localhost:8501`).
- ¡Listo! Ya puedes usar la aplicación.

### Para detenerlo
Cuando termines, regresa a la terminal y presiona **Ctrl + C** para detener el servidor.
